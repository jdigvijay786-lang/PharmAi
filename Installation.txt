## Installation

### 1. Install Ollama

Download and install Ollama from:

https://ollama.com/download

Verify installation:

```bash
ollama --version
```

Download a model:

```bash
ollama pull llama3
```

Start Ollama:

```bash
ollama serve
```

---

### 2. Install Flask

Create and activate a virtual environment:

```bash
python -m venv venv
```

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install flask requests
```

---

### 3. Run the Application

Start the Flask server:

```bash
python app.py
```

The application will be available at:

```text
http://localhost:5000
```

PharmAI is now ready to use with a local Ollama-powered AI backend.
