## 📖 Overview

PharmAI is an intelligent AI-powered study assistant designed specifically for pharmacy students. It helps students understand complex pharmaceutical concepts, generate study materials, prepare for exams, and access instant academic support anytime.

Whether you're studying Pharmacology, Medicinal Chemistry, Pharmaceutics, Pharmaceutical Analysis, Pharmacognosy, or Clinical Pharmacy, PharmAI acts as your personal AI tutor.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/pharmai.git
cd pharmai
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

```env
OPENAI_API_KEY=your_api_key
DATABASE_URL=your_database_url
```

### Run the Application

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
